# Ahmed Mody — interactive portfolio (V2)

Static site, no build step. Deploy the folder as-is to Vercel (`vercel deploy --prod`), or open index.html via any static server.

- `data.js` — every design (title, client, section) and partner logo, extracted from the PDF portfolio.
- `assets/work` full-size WebP for the zoom viewer, `assets/thumb` grid thumbnails, `assets/logos` partner logos.
- Deep link to a design: `/#view-w05`.
